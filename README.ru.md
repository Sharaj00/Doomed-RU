# Doomed RU

Русская локализация мода **[Doomed](https://www.curseforge.com/minecraft/mc-mods/doomed)**
(`doomedmatu`) 0.3.6 — Minecraft 1.20.1, Forge.

*[English version](README.md)*

Только клиент. **Jar самого Doomed не меняется** — оставьте оригинальный
`doomedmatu-0.3.6.jar` и положите аддон рядом.

---

## Что он делает

Doomed выводит текст тремя разными способами, и каждый требует своего подхода.
Аддон закрывает все три.

| Откуда текст | Объём | Чем переводится | Готово |
|---|---|---|---|
| `lang/en_us.json` — штатные ключи локализации | 929 ключей | обычный lang-файл | **929 / 929** |
| Строки, зашитые в код | ~8 700 констант | подмена на лету | ~75 % |
| JSON датапака — журнал, торговцы, воображаемый друг, достижения | 162 записи | подмена на лету, записью целиком | **162 / 162** |

Названия предметов и блоков, подсказки и субтитры идут по первому каналу —
они переводятся обычным lang-файлом, без всяких ухищрений.

Почти всё остальное — HUD, панель сортировки, планшет WITNESS, экран настроек,
выбор режима — это **английские строки, зашитые прямо в код**. В моде 895 мест,
где вызывается `Component.literal(...)`. Ни один lang-файл до них не дотянется,
и ровно поэтому аддон вообще существует.

---

## Как это работает

### Перехват

Аддон ничего не правит в Doomed. Он встраивается в ванильный конвейер
отрисовки двумя слоями миксинов:

**Основной — `LiteralContents.visit()`.** Всё, что мод отдаёт через
`Component.literal(...)`, проходит через этот метод в момент отрисовки или
замера ширины. Одна точка покрывает подписи кнопок, заголовки экранов,
подсказки предметов, перенос по словам и текст, который за мод рисует уже
ванильный код.

**Дополнительный — `DoomedTextMixin`.** Нацелен на 178 классов Doomed и ловит
строки, которые рисуются напрямую, минуя `Component`: `GuiGraphics.drawString`,
`drawCenteredString`, `Font.width`.

Перехваченная строка ищется в словаре и подменяется по дороге к отрисовке. Сам
объект `Component` при этом не меняется, поэтому логика мода, сравнивающая
строки, продолжает работать.

> **Заметка для тех, кто делает похожий аддон.** Перехватывать сам
> `Component.literal` через `@Redirect` **не работает**. `Component` — это
> интерфейс, а `literal` — его статический метод; процессор аннотаций Mixin
> разбирает такую цель иначе, чем обычный виртуальный метод обычного класса,
> и инъекция молча не применяется при `"defaultRequire": 0`. Надёжно
> получается через `LiteralContents.visit()` — обычный метод обычного класса.

### Цепочка подстановки

Строка, идущая на отрисовку, проверяется по порядку:

1. **Точное совпадение** — `"SKIN"` → `"КОЖА"`.
2. **Числовой шаблон** — `"100 BPM"` сводится к ключу `"{} BPM"`, число
   возвращается на место. Одна запись покрывает всю шкалу.
3. **Свободный шаблон** — то же для текстовых подстановок. Мод строит заметки
   по делу как `String.format("%s opened.", часть)`, поэтому
   `"Left Foot opened."` попадает в `"{} opened."` — и захваченная часть тела
   тоже переводится.
4. **Префикс** — часть текста Doomed печатает посимвольно. Незаконченный кадр
   получает пропорциональный кусок перевода, и анимация набора идёт
   по-русски, а не мигает между языками.
5. **Составной текст** — несколько предложений подряд, из которых словарю
   известны не все. Мод склеивает описание состояния с текущими эффектами;
   целиком такой строки в словаре быть не может, поэтому она переводится
   по предложениям, начиная с самого длинного известного куска.

Результат каждой строки кэшируется, так что на кадре ничего не считается.
Кэш ограничен и сбрасывается при переполнении — показания HUD дают
бесконечный поток разных строк.

### Чужие моды не задеваются

Словарь собран из самого jar Doomed, поэтому его ключи по построению
относятся к Doomed. Вдобавок короткие общие слова (`Done`, `Combat`, до двух
слов) подменяются только на экранах Doomed. Длинные фразы достаточно
уникальны, чтобы переводить их где угодно.

## Установка

1. Соберите (или скачайте) `doomedru-1.0.0.jar`.
2. Положите его в `.minecraft/mods` рядом с `doomedmatu-0.3.6.jar`.

Только клиент — на сервер ставить не нужно.

Проверка в игре:

```
/doomedru
```

Команда показывает размер словаря, встроился ли перехват на самом деле и
сколько строк через него прошло. Если самопроверка говорит, что перехват не
работает, — дело в сборке, а не в словаре.

| Команда | |
|---|---|
| `/doomedru` | статистика и диагностика перехвата |
| `/doomedru reload` | перечитать `config/doomedru/ru_ru.json` без перезапуска |
| `/doomedru dump` | выгрузить все непереведённые строки, что были на экране |
| `/doomedru toggle` | выключить перевод, чтобы сравнить с оригиналом |
| `/doomedru targets` | в какие классы встроился перехват |

Любую строку можно переопределить без пересборки — положите её в
`config/doomedru/ru_ru.json` и выполните `/doomedru reload`:

```json
{
  "strings":  { "SKIN": "ПОКРОВ" },
  "patterns": { "{} BPM": "{} уд/мин" }
}
```

## Сборка

Нужны **JDK 17** и jar Doomed в папке `libs/` (только на время компиляции —
процессор аннотаций Mixin проверяет, что все 178 классов-целей существуют;
в готовый мод этот файл не попадает).

```
gradlew.bat build
```

Результат — `build/libs/doomedru-1.0.0.jar`.

Бинарника Gradle Wrapper в архиве нет: возьмите `gradlew`, `gradlew.bat` и
папку `gradle/` из официального [Forge 1.20.1 MDK](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html).

## Инструменты переводчика

Словарь сверяется с jar мода, а не угадывается по игре.

```
python3 tools/extract_strings.py     # эталон: все строки из jar
python3 tools/audit_dict.py          # покрытие, типографика, единство терминов
python3 tools/audit_dict.py --by-class   # что осталось, в виде очереди работ
python3 tools/gen_targets.py         # пересобрать список целей миксина
```

`extract_strings.py` читает три источника: пул констант каждого класса, JSON
датапака и `lang/en_us.json`. Он также восстанавливает **рецепты склейки
строк** — javac кладёт `"Вы устаёте (" + n + "% выносливости)..."` одной
константой с метками подстановки — и превращает их в ключи-шаблоны с `{}`.
Именно так переводятся описания состояний с живыми значениями.

После обновления Doomed запустите все четыре; аудит покажет, что изменилось.

## Заметка для автора Doomed

Этот аддон — обходной путь, и довольно громоздкий. В моде 895 вызовов
`Component.literal(...)` против 109 `Component.translatable(...)`, то есть
большая часть интерфейса — это зашитый английский, а не ключи локализации.
Поэтому любой перевод вынужден перехватывать отрисовку вместо того, чтобы
просто поставляться lang-файлом.

Китайский `zh_cn.json` в jar хорошо показывает эффект: он покрывает 912 ключей
из 929 — для своего канала это полноценный перевод, — но китайский игрок
всё равно видит полностью английские HUD, панель сортировки и планшет, потому
что эти строки через систему локализации не проходят.

Если перенести текст интерфейса на ключи `Component.translatable(...)`, любой
язык можно будет поставлять обычным ресурспаком, а аддоны вроде этого
сожмутся до lang-файла. Если это когда-нибудь окажется интересно — готовая
отправная точка уже есть в `build/doomedru-strings.json`: 8 700 констант и
821 шаблон склейки, сгруппированные по классам.

Ни на чём не настаиваем — мод отличный, и это скорее данные, чем претензия.
